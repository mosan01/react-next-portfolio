# ポートフォリオ（Next.js）

就活・課題提出用に作っているポートフォリオサイトです。
「できるだけ見やすく、触って楽しいUI」を目標にしてます。

## できること

- Home / About / Contact の静的ページ
- Blog（microCMS 連携）
	- 一覧表示 / 詳細表示
	- 詳細ページは見出し（h2/h3）から目次を自動生成
- テーマ切替（デフォルトはライトで開始）

## ページ構成

- `/` : Home
- `/about` : プロフィール / スキル / 趣味
- `/contact` : 連絡先
- `/blog` : 記事一覧
- `/blog/[id]` : 記事詳細

## 技術スタック

- Next.js
- React
- TypeScript
- microcms-js-sdk
- CSS Modules

## メモ

- デザインはページごとに統一感が出るよう、背景やカードの見た目を揃えています。
- もし microCMS 未設定でも、Blog ページに設定方法が表示されるようにしてあります。
